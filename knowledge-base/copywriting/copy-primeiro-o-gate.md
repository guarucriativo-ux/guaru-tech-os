# Copy primeiro — O GATE (ritual obrigatório antes de qualquer design)

> Regra Nº0 da fábrica (Marcos 2026-06-26): *"design que não cria copy entrega bosta. Isso sim é regra.
> Se entregarmos o que não converte, tudo se acaba, de nada adianta, designer."* A faculdade JÁ tem o
> cânone de copy — o pecado nunca foi falta de conteúdo, foi **não usá-lo** (escrever copy no escuro).
> Este doc não re-ensina copy: ele é o **portão de processo** que torna o cânone obrigatório e na ordem
> certa. Cumprir este gate é pré-condição pra abrir qualquer HTML. Vale pra todo cliente/nicho.

## Por que existe (a falha que ele fecha)
Craft visual bom + copy rasa = peça reprovada. O design vende o que a copy diz; se a copy não estuda a dor
nem o que converte, a peça mais bonita não fecha cliente. **A copy vem primeiro; o design veste a copy.**

## O GATE — 5 passos, nesta ordem, ANTES de tocar no layout
Cada passo aponta pro doc fundo que já existe na faculdade. Não pular nenhum.

1. **Pesquisar a DOR + o que CONVERTE (nunca escrever no escuro).**
   - Quem é o avatar e qual a dor REAL dele (não a genérica)? Voz do cliente: as frases exatas que ele fala/
     teme/deseja. Qual ângulo está quente nesse nicho agora?
   - Rigor de bastidor, sem jargão na peça. → `copy-fundamentada-e-fact-checking.md`.

2. **Escolher o ângulo quente pelo NÍVEL DE CONSCIÊNCIA.**
   - A mensagem muda conforme o quanto o público sabe (inconsciente → mais consciente). Mirar o estágio certo
     é o que faz converter. → `../marketing/funil-e-consciencia-canone.md` (Schwartz, 5 níveis).

3. **Escrever HOOK-FIRST (a capa carrega ~80%).**
   - Estrutura PAS ou AIDA; slide 1 = dor/ganho/open-loop em <12 palavras; cada slide puxa o próximo
     (slippery slide / open loop). → `estrutura-carrossel-venda.md` + `copy-persuasao-canone.md`.
   - Cliente é o HERÓI, marca é o GUIA (StoryBrand). 1–2 gatilhos por peça, com ética. → `gatilhos-mentais.md`.

4. **Editar afiado.** Primeira versão é gorda: cortar 20–30%, um pensamento por frase, zero jargão, verbo no
   comando no CTA. → `copy-persuasao-canone.md` §5.

5. **AUTO-CHECK de conversão (o portão).** Só passa pro design se responder SIM a tudo abaixo.

## Checklist do portão (se algum NÃO → volta pra copy, não diagrama)
- [ ] Estudei a dor real e o que converte nesse nicho (não inventei do nada)?
- [ ] O ângulo bate com o nível de consciência do público que vai ver?
- [ ] A capa para o scroll sozinha (dor/ganho/open-loop, concreta, <12 palavras)?
- [ ] Cada slide dá gancho pro próximo (não fecha o assunto cedo)?
- [ ] Cliente é herói e a marca é guia (não me coloquei de herói)?
- [ ] Tem CTA claro e único, com verbo no comando?
- [ ] Cortei a gordura (um pensamento por frase, sem jargão)?
- [ ] Eu **compraria/agiria** vendo isso? Resolve uma dor de verdade?

> Bonito não salva fraco. Copy reprovada no portão **não vira HTML** — volta pro passo 1.
