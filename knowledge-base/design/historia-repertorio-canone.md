> **Por que um designer estuda história:** não pra erudição — pra ter **repertório**. Quem conhece os
> movimentos **reconhece registros** ("isto é suíço", "isto é Bauhaus") e **rouba com consciência** (T.S.
> Eliot/Picasso: *"bons artistas copiam, grandes roubam"* — roubar = absorver e transformar, nunca clonar).
> Sem repertório, o designer reinventa o pior e cai no genérico. Casa com o catálogo dos 8 registros da Base Mãe.

## Os movimentos que ainda mandam na peça de hoje (o essencial, não a enciclopédia)

- **Bauhaus (1919–33, Alemanha):** "forma segue função"; geometria, sans-serif, abstração, grid, união
  arte+indústria. **É a raiz do design moderno.** → minimalismo funcional, sans geométrica, layout limpo.
- **Estilo Tipográfico Internacional / Suíço (1950s):** Müller-Brockmann & cia — **grid**, Helvetica,
  assimetria objetiva, clareza acima de tudo, foto preto-e-branco. → a base do nosso layout limpo/grid (N1);
  o registro "clean/corporativo confiável".
- **Construtivismo russo (1920s):** diagonal dinâmica, vermelho/preto, tipografia como elemento gráfico,
  geometria militante. → energia, cartaz de impacto, tipografia que vira imagem (registro "agressivo").
- **Art Nouveau (1890s):** ornamento orgânico, linhas curvas, natureza. → o "decorativo/artesanal" elegante.
- **Art Déco (1920s–30s):** geometria luxuosa, simetria, dourado, sofisticação. → premium/glamour (joalheria!).
- **Movimento moderno americano / Escola de NY (1940s–60s):** Paul Rand, Saul Bass — **logo conceitual**,
  ideia simples e espirituosa, identidade corporativa. → branding/logo (N3), o "conceito numa forma".
- **Psicodélico (1960s), Punk/DIY (1970s):** ruptura, colagem, "feio proposital", energia anti-sistema. →
  registro jovem/cru/autêntico (UGC, cartaz de show).
- **Pós-moderno / New Wave (1980s, Weingart/Carson):** quebra das regras suíças, sobreposição, caos
  controlado, tipografia expressiva. → a licença pra "quebrar o grid com intenção" (N1/Samara).
- **Digital / contemporâneo:** do flat ao "novo feio"/maximalismo/anti-design, brutalismo web, retrô-revival.
  → as modas atuais do feed — usar com consciência de que são CICLOS (o atemporal sobrevive; a moda data).

## Princípios transferíveis que a história ensina
1. **Estilo é escolha consciente, não acaso** — cada movimento resolvia um problema/contexto. Escolher um
   registro = escolher um significado (suíço = confiança; déco = luxo; punk = ruptura).
2. **O atemporal vence a moda** — Bauhaus/suíço seguem de pé; tendências de feed datam rápido. Construir marca
   no atemporal, temperar com a moda (não o contrário).
3. **Roubar como artista** — absorver a LÓGICA do registro e vestir com a nossa voz/DNA (≠ clonar uma peça).
   É exatamente a doutrina da régua (estudar o mercado → destilar → autoral).
4. **Repertório = antídoto contra o genérico** — quanto mais registros o designer conhece, menos ele cai no
   default sem graça.

## Como isto MUDA a nossa peça (backward da entrega)
1. **Nomeie o registro** antes de criar ("esta peça é suíça-limpa? déco-premium? construtivista-impacto?") —
   decisão consciente, casada ao nicho/humor (camada 2 + Base Mãe dos 8 registros).
2. **Ancore no atemporal**, tempere com tendência — não construa a marca em cima de uma moda.
3. **Roube a lógica, não a arte** — absorva o movimento, entregue autoral com o DNA do cliente.
4. **Use o repertório pra fugir do default** — se a peça está "genérica", buscar um registro com intenção.

## Erros que este módulo proíbe
Criar sem nomear o registro (estilo por acaso) · construir marca numa moda passageira · clonar uma referência
(em vez de roubar a lógica) · repertório pobre → genérico · confundir "atemporal" com "datado".
