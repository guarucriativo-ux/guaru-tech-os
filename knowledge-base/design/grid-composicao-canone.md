> **A tese de Müller-Brockmann:** o grid é **sistema de ordem a serviço da clareza** — não uma jaula, uma
> ferramenta de comunicação. *"O grid é a expressão de uma certa atitude mental: o designer vê seu trabalho
> como ordem racional."* **A tese de Samara:** primeiro **dominar** o grid; só então **quebrá-lo com intenção.**
> A Base Mãe já prega "morte à grade rígida" — mas a quebra só vale se você sabe o que está quebrando. Este
> módulo é o "dominar antes de quebrar".

## 1. Por que grid (a função, não a estética)
- **Clareza/leitura:** alinhamento ativa a continuidade da Gestalt → o olho flui. 
- **Coesão:** num conjunto (carrossel/feed), o mesmo grid faz tudo "ser da mesma família" (consistência por
  construção — bate com nosso anti-genérico).
- **Velocidade/escala:** decisões viram sistema → a fábrica produz N peças coerentes sem recompor do zero.
- **Hierarquia espacial:** o grid posiciona por importância, não por acaso.

## 2. Anatomia do grid (vocabulário)
- **Margens** (a moldura/respiro — generosas = premium; é a nossa "zona segura anti-corte" também).
- **Colunas** + **gutters** (calhas entre colunas).
- **Linhas/rows** e **módulos** (coluna × row = retângulos que governam o layout — grid modular).
- **Baseline grid** (linhas-base do texto): TODA medida vertical deriva do ritmo da entrelinha. É o que faz
  texto de colunas diferentes alinhar — o profissionalismo "invisível".
- **Campos espaciais:** zonas do grid agrupadas pra papéis (imagem, título, corpo).

## 3. Tipos de grid (escolher pela função)
- **Coluna única (manuscrito):** texto corrido / peça simples. 
- **Multicolunas:** flexível, mistura texto/imagem (2–4 colunas no nosso 1080).
- **Modular:** colunas + rows → grade de módulos; ótimo pra **carrossel/grid de feed** e tabelas/preços.
- **Hierárquico:** grid intuitivo ajustado ao conteúdo (não matemático) — quando o conteúdo manda.
- **Baseline:** sobreposto a qualquer um pra travar o ritmo vertical do texto.

## 4. Princípios de Müller-Brockmann
Modularidade · **proporção** (relações proporcionais entre módulos = harmonia) · **flexibilidade** (o grid
serve o conteúdo, não o contrário) · alinhamento consistente · **simplicidade/clareza/elegância**. O grid é
**meio, não fim** — se aparecer "design de grade", falhou.

## 5. Quebrar o grid com intenção (Samara)
- A quebra só LÊ como proposital se há um grid claro pra contrastar. Sem grid, quebra = bagunça (= o nosso
  "quase alinhado por acidente", proibido).
- **Como quebrar bem:** um elemento sangra/atravessa (bleed), um título estoura a coluna, uma foto fura a
  margem — **um** gesto forte contra um sistema calmo. Tensão controlada (Base Mãe: sobreposição/sangria).
- **Ritmo:** alternar cheio/vazio, denso/respirado entre slides cria narrativa visual no carrossel.

## 6. Composição além do grid (síntese com F1)
- **Ponto focal único** por peça (peso visual — F1). 
- **Regra dos terços / pontos de tensão** como ponto de partida (não lei).
- **Equilíbrio assimétrico** ancorado no grid: peso de um lado, contrapeso (espaço/grafismo) no outro.
- **Espaço negativo é elemento ativo** (Prägnanz) — não "sobra" pra preencher.

## Como isto MUDA a nossa peça (backward da entrega)
1. **Defina margem generosa + colunas** antes de jogar conteúdo (não compor "no olho" solto).
2. **Carrossel = grid modular compartilhado** entre slides → coesão automática.
3. **Baseline/ritmo vertical** consistente (espaçamentos múltiplos de uma unidade base).
4. **Alinhe ao grid de verdade** (continuidade) — e quando quebrar, **um gesto forte e óbvio**, não dois tímidos.
5. **Espaço negativo planejado**, não acidental.

## Erros que este módulo proíbe
Compor sem margem/coluna (tudo flutuando) · "quase alinhado" (grid frouxo) · quebrar sem ter grid (vira
bagunça, não estilo) · slides do mesmo carrossel com grids diferentes (perde coesão) · preencher todo espaço
(medo do vazio) · "design de grade" aparente (rígido por acidente).
