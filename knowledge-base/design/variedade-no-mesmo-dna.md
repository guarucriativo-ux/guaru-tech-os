## A regra que eu estava quebrando
**Consistência de marca = reconhecimento de PADRÃO, NÃO repetição de layout.** Um template fixo repetido
não é "consistente" — é monótono e genérico. A marca forte mantém os ELEMENTOS fixos e **varia a
composição infinitamente**. Provas clássicas: Google Doodles (logo fixo, ilustração muda todo dia);
City of Melbourne (o "M" é fixo, o padrão interno muda). Mesmo DNA → infinitos visuais.

> **Foto stock em duotone é UMA técnica entre milhares — não é "a regra".** É uma carta do baralho, não
> o baralho. Tratar uma técnica como o método = empobrecer o design e cair no template.

## Sistema de marca flexível — 3 camadas (o modelo mental)
- **FIXO (nunca muda — é o reconhecimento):** preto `#0A0A0A` + off-white `#F2F1EE` + gradiente
  magenta→laranja→violeta; tipografia (Archivo/Cormorant/Poppins); **selo ∞**; **kicker** topo+rodapé.
- **FLEXÍVEL (varia dentro de parâmetros):** QUAL arquétipo de layout entra, qual motivo é protagonista,
  intensidade do gradiente, paleta de apoio (navy/creme na prova), com/sem foto, tipo de foto.
- **LIVRE (infinito):** a COMPOSIÇÃO em si — escala, hierarquia, recorte, sangria, sobreposição, ritmo.
A variedade mora nas camadas FLEXÍVEL+LIVRE; a marca mora na FIXA. As duas convivem — é o ponto.

## As alavancas que GERAM variedade (composição — toolbox)
Cada peça pode girar estas alavancas de um jeito diferente e sair única, com o mesmo DNA:
- **Escala / contraste de tamanho** — a alavanca nº1 de hierarquia. Use **≤3 tamanhos**, mas com
  contraste EXTREMO (palavra gigante × corpo pequeno). Variar qual elemento domina muda tudo.
- **Hierarquia / foco** — o que o olho vê 1º, 2º, 3º. Mudar a ordem = nova peça.
- **Espaço negativo** — respiro generoso OU densidade proposital; alternar entre peças.
- **Contraste** — claro×escuro (off-white vs preto), grosso×fino, foto×tipografia.
- **Ritmo / movimento** — F-pattern/Z-pattern, diagonais, sangria, sobreposição.
- **Variedade de FORMA** — retângulo, orgânico, faixa, mockup, diagrama, sem-foto.
**Regra de motor:** girar essas alavancas por peça e por slide (cada slide um "movimento" diferente),
nunca repetir o mesmo enquadramento só trocando texto (= o defeito documentado na Base Mãe, "carrossel").

## Como o motor aplica (substitui o template rígido)
O molde NÃO é um layout — é um **sistema que rotaciona ARQUÉTIPOS de composição** (ver
[arquetipos-de-layout-social.md](arquetipos-de-layout-social.md)) + gira as alavancas acima. Cada
**geração** sorteia/escolhe arquétipos diferentes → **visual diferente, DNA igual**. É assim que a
Tramontina faz: ~18 arquétipos distintos, todos inconfundivelmente a mesma marca.

## Capa/hook (regra de carrossel da pesquisa)
Cover = **hook bold (5–8 palavras, maior texto) + pattern interrupt (cor de alto contraste, rosto
expressivo OU grafismo dramático) + gatilho de curiosidade**. 1 ideia por slide, ~10–15 palavras, cada
ideia ancorada num visual/ícone. Dois tipos complementares (display + corpo), alinhados a um baseline grid.

## A variedade vale em TODO slide — sobretudo a PROVA (feedback Marcos 2026-06-24)
Erro a NÃO repetir: variar só os 2 frames da marca (hook + pitch) e deixar o miolo-prova templatado.
**Um molde de N vagas que só gira a moldura ainda é molde.** A regra de variedade vale em **todo slide**.
- **O miolo-prova É a prova social.** No feed, o psicólogo vê post após post: [nossa chamada → o que
  entregamos]. Se a entrega é sempre igual, a prova social morre. **Cada entrega tem que ser única.**
- **O conteúdo do nicho nasce do ZERO via PESQUISA de mercado** (a máquina acha o tema, compõe arte única).
  **Nada surge do nada.** A **única coisa constante é o DNA** (paleta + tipografia do nicho — e, no cliente
  real, o DNA DELE). A arte — diagramação, estrutura, grafismos, nº de slides — é outra toda vez.
- Implicação de motor: a prova **não** é uma sequência fixa de papéis (capa/conceito/sinais/acolhimento)
  reskinada. É um **post researchado e composto único**. Deck pequeno → peças parecidas: diversificar de
  verdade (e fugir de dois arquétipos quase idênticos, ex.: capa e acolhimento ambos serifa-navy sem foto).

## Morte à esfera/orbe genérica (feedback Marcos 2026-06-24)
O "orbe de gradiente flutuando" que eu repetia é **péssimo e proibido** — é o gradiente genérico de tech
(o erro nº1 que o próprio brand-DNA avisa). O gradiente da marca entra via os MOTIVOS reais (selo ∞,
ribbon/fita, palavra two-tone, full-gradient slide, objeto 3D sobre círculo), nunca como bola solta.
