A régua do **estilo/nível do próprio estúdio** (posts do @guaruestudio): design bold/moderno de agência-estúdio
que te faça babar — o sarrafo que você quer que os posts do estúdio alcancem. Pode incluir as suas próprias

## Padrão de nome
`estudio--<movimento>--NN.jpg`
- **movimento** = a jogada distinta que ela ensina (ex.: `two-tone-bold`, `serifa-italica-acento`, `swoosh-grafismo`,
  `mockup`, `tipo-como-layout`, `grid-editorial`, `colagem`).
- Ex.: `estudio--two-tone-bold--01.jpg`

## Regras (mesma doutrina)
- **Diversidade de MOVIMENTOS, não contagem** — cada imagem deve ensinar algo diferente. ~15–30 pra começar.
- **Anti-clone** — espalhar entre fontes pra absorver o princípio, não imitar um estúdio só.
- **Git:** screenshot pequeno → entra no Git (o Olho precisa enxergar, inclusive na nuvem).
- A identidade-base do estúdio (lime + preto + serifa itálica + swoosh) está em `../../brand-dna.json`.
