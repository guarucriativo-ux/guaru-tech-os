# Análise das Referências — Lanche do Seu Zé

Referências enviadas pelo cliente (2026-06-22) como imagens em resolução cheia. Não foi possível
gravar os binários a partir do chat; esta análise é a referência reusável (tokens em
`../brand-dna.json`).

1. **Flippin' Good Fries** — creme + laranja-vermelho; tipografia retrô desenhada à mão (script +
   bold condensado chunky); ilustração de linha + halftone; pôster de lanchonete vintage, monocromático.
2. **Bundry "Smokey Cravings / Crave the Smoke"** — vermelho forte + branco + creme; mascote
   cartoon (rubber-hose), script bold no logo; foto real de burger sobre vermelho; padrão de ícones;
   packaging. Fast-food coeso, brincalhão.
3. **T.T. Burger "Hambúrguer de Verdade"** — preto + dourado; foodporn escuro/premium; gourmet.
   (registro premium — usar com parcimônia; o cliente é mais pop que gourmet.)
4. **Dia Mundial do Hambúrguer / Mega Burger** — creme + rabiscos mostarda + foto de burger + tag
   vermelha de preço; template social BR (logo, Rappi/iFood/Uber). Códigos de promoção/delivery.
5. **Border Burrito** — creme + vermelho/preto; selos/carimbos retrô; bold condensado + script.
6. **Yum Eat / Famous Tacoo** — vermelho/creme/marrom; mascotes rubber-hose anos 30; lettering
   groovy/blobby; cards alternando cor.
7. **Supremu's Burger "Impossível resistir!"** — vermelho + creme; lettering bold rounded GIGANTE
   com halftone + motion lines; foodporn extremo (close de burger); barra de delivery + WhatsApp no
   topo. **É o alvo principal do carrossel de desejo.**

## DNA convergente
Vermelho quente + creme + acento mostarda/laranja · lettering bold rounded de impacto + script de
acento + condensada bold · halftone, motion lines, doodles de linha, selos, tag de preço ·
foodporn real protagonista · códigos de social BR (delivery, WhatsApp). Energia retrô-divertida.

## Aplicação aos 2 carrosséis pedidos
- **Carrossel 1 (desejo):** registro Supremu's — foodporn + lettering de impacto com halftone.
- **Carrossel 2 (chapa/processo):** registro educativo — foto de chapa/smash + condensada bold +
  script no termo-chave, provando "hambúrguer de verdade". Ângulos de mercado: smash na chapa,
  blend de carne, ingrediente fresco/rastreável, pão e molho da casa (tendências 2025-26).
