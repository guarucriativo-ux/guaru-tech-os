# Audience Insights — Arquitetura de Alto Padrão

Hipóteses de público do nicho (validar/ajustar a cada cliente real; ainda não comprovado em
campanha — origem: lançamento Studio Meta-Espaço, 2026-06-22).

- **Quem decide:** casais 35–55, alta renda, ou empresários contratando projeto autoral.
  Já têm referência estética; o que falta é confiança em quem executa.
- **Dor real:** medo de "casa de catálogo" / projeto genérico que envelhece mal. Valorizam
  exclusividade e a sensação de terem sido entendidos.
- **Ciclo longo:** decisão de meses, alto ticket. Conteúdo educativo (autoridade) aquece antes
  de qualquer CTA. Conversão é **consultoria/conversa**, não compra por impulso.
- **Gatilhos que funcionam:** autoria, curadoria, atemporalidade, "verdade" dos materiais,
  escala humana. **Repelem:** linguagem de promoção, urgência artificial, desconto.
