## Como o Marcos abastece (o workflow)

3. Eu **leio do disco**, escrevo a **ficha de anatomia** de cada uma em `../referencias.md`, e pronto:

## Padrão de nome do arquivo
`<conta>--<movimento>--<NN>.jpg`
- **conta** = handle sem @ (ex.: `nicoleholz`, `psilarihoffmann`). Espalhar entre **2–3 contas** (anti-clone).
- **movimento** = a jogada distinta que ela ensina, curtinho em kebab (ex.: `colagem-envelope`,
  `banda-foto-split`, `tipo-como-layout`, `foto-fullbleed-overlay`, `escala-extrema`).
- **NN** = sequencial 01, 02…
- Ex.: `nicoleholz--colagem-envelope--01.jpg` · `psilarihoffmann--script-foto-frame--01.jpg`

## Regras do banco (resumo da doutrina)
- **Referência é régua, não regra** — serve pra medir NÍVEL (diagramação, peso, hierarquia, escala,
  respiro, tipo×imagem), não pra copiar a peça.
- **Diversidade de MOVIMENTOS, não contagem** — cada arquivo deve ensinar algo **diferente**. ~15–30
  refs-ouro pra começar; cresce só quando uma adiciona movimento novo.
- **Anti-clone** — 2–3 contas pra absorver o princípio do nicho, não imitar uma designer.
- **Git:** régua é screenshot pequeno → **entra no Git** (pra o Olho enxergar na nuvem). Só foto pesada de
  cliente/output fica fora.
- **Camada:** isto é a régua de **NICHO** (psicologia editorial calmo). A régua de **marca loud** (agência)
  é outra coisa; o Olho mede a parte certa contra a régua certa.
