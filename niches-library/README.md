# Niches Library

Biblioteca de regras de sucesso, prompts validados e lógicas específicas por setor de mercado.

Cada nicho ganha sua própria subpasta quando o primeiro cliente daquele setor for cadastrado
(ex: `niches-library/dtf-apparel/`, `niches-library/estudio-design/`). Um aprendizado só entra
aqui depois de comprovado em pelo menos um cliente — ver "Ciclo de Aprendizado do Agente" em
[CLAUDE.md](../CLAUDE.md).
