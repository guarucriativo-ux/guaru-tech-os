# Stock licenciado usado em peças (NÃO é a gaveta do cliente)

> Foto de banco de **licença livre** baixada pra usar numa peça. Fica aqui (recurso da fábrica, não material
> do cliente) — **não** em `Projetos/<cliente>/assets`, que é só pro material do PRÓPRIO cliente.

- **Foto é fresca por post.** Banco de imagem tem milhões de fotos; cada peça usa uma diferente. **Não se
  reusa a mesma foto entre clientes** — guardar aqui é só organização/licença, não "banco pra repetir".
- Cada arquivo tem `.LICENSE.txt` ao lado (fonte, autor, link, termos). Conferir antes de usar.
- **O que de fato se acumula e replica entre clientes NÃO são as fotos — é o CONHECIMENTO** de como escolher
  e aplicar foto (serve à copy · domínio certo · sem direito de terceiro · não repetir na peça). Isso mora na
  **faculdade**: `knowledge-base/design/craft-primeiro-o-gate.md` + `foto-no-conteudo-padrao-da-fabrica.md`.
